# Contributing

Thank you for contributing to Smart Update.

## Development Rules

Before submitting any change:

- Code must pass `bash -n`.
- Code must pass `shellcheck`.
- Tests must pass.
- Update documentation if needed.
- Update `PROGRESS.md`.
- Keep one feature per commit.

## Coding Style

- Use clear function names.
- One responsibility per module.
- Keep functions small.
- Prefer readability over cleverness.

## Project Philosophy

Every contribution must reinforce:

- Security
- Transparency
- Reliability
- Modularity
