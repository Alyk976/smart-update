# Smart Update v1.1.2

Smart Update v1.1.2 is a maintenance bug-fix release for the stable 1.1 line.

## Fixed

- Do not emit a false `[ERROR]` when `checkupdates` returns exit status `2`.
- Exit status `2` continues to mean that no official Arch Linux updates are available.
- Keep the global `ERR` trap for genuine runtime failures while handling the normal no-update path conditionally.

## Validation

- Bash syntax validation passed.
- ShellCheck passed.
- Arch Linux CI build/install passed.
- Automated test suite increased to 47 tests.
- systemd unit validation remains part of CI.

## Compatibility

This release does not change:

- the deterministic `ALLOW / WARNING / BLOCK` decision model;
- the public exit-code contract;
- policy semantics;
- AUR defaults;
- installation safety gates.

The package source is pinned to commit `dd289b0e7578f9887b66ca215b8b46cd266db12a`, which contains the runtime fix and its CI-clean regression test.
