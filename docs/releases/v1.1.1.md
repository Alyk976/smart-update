# Smart Update v1.1.1

Smart Update v1.1.1 is a focused maintenance release for the stable 1.1 line.

## Fixed

### Accurate Foreign package reporting when AUR updates are disabled

When `ENABLE_AUR_UPDATES="no"`, Smart Update intentionally does not perform AUR classification. In v1.1.0, all installed Foreign packages were still placed in the unknown-Foreign list and the policy message could incorrectly describe them as packages that were absent from the AUR.

v1.1.1 corrects the wording so that, when AUR lookup is disabled, Smart Update now reports that Foreign packages were detected but AUR classification was not performed.

Example:

```text
13 paquet(s) Foreign détecté(s). Recherche AUR désactivée ; classification AUR non effectuée. Aucune modification automatique.
```

When AUR analysis is actually enabled and completed, packages that are confirmed not to exist in the AUR continue to be reported as such.

## Safety impact

This release does **not** broaden automatic package modification. With AUR updates disabled, Foreign packages remain untouched. The change only makes the policy result and report semantically accurate.

The deterministic policy gate, guarded execution flow, exit-code contract and package-manager authority are unchanged.

## Validation

The fix includes a regression test covering the disabled-AUR case with representative Foreign packages including `google-chrome`, `yay` and `paru`.

Validation completed before release preparation:

- targeted Foreign package policy test: passed;
- complete automated suite: **46/46 passed**;
- zero automated test failures.

## Upgrade

Arch package version:

```text
smart-update 1.1.1-1
```

Release tag:

```text
v1.1.1
```

After downloading the package and checksum file from the GitHub release:

```bash
sha256sum -c SHA256SUMS
sudo pacman -U smart-update-1.1.1-1-x86_64.pkg.tar.zst
```

Administrator configuration under `/etc/smart-update/` remains preserved by the package metadata.
