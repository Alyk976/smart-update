# Smart Update v1.1.0

Smart Update v1.1.0 is the second stable release of the deterministic,
policy-driven update decision engine for Arch Linux.

## Highlights

- Stable official update eligibility checks based on libalpm transaction data.
- Deterministic `ALLOW` / `WARNING` / `BLOCK` policy aggregation.
- Audit and guarded operating modes.
- Stable critical updates remain visible as `WARNING` when policy allows them.
- Explicit blocking of testing, staging, unstable, VCS and pre-release candidates.
- libalpm inspection of removals, replacements, additions and transaction questions.
- Detection of transactions requiring manual Pacman decisions.
- Official transaction drift protection before guarded execution.
- Optional stable AUR discovery and targeted update support through `yay`.
- Fail-closed validation of the non-root AUR identity.
- Post-official `yay`/libalpm compatibility recheck.
- Unknown Foreign packages are reported and never modified automatically.
- Structured logs and final reports.
- systemd service and daily timer integration.
- Apache-2.0 license.

## Runtime safety

A final `BLOCK` always prevents package installation.

Transactions that require a Pacman choice that Smart Update deliberately refuses
to automate return:

```text
34 MANUAL_TRANSACTION_REQUIRED
```

Policy blocks return:

```text
29 POLICY_BLOCK
```

Both `29` and `34` are configured as controlled successful outcomes for the
systemd service. Other non-zero results remain failures.

## AUR security note

AUR automation is disabled by default in v1.1.0.

The current AUR installation path does not yet separate a complete non-root
builder from a minimal root installer. Timer-based AUR automation is therefore
not presented as fully hardened. Official Arch Linux updates remain supported
independently with AUR disabled.

## Validation

Smart Update v1.1.0 passed:

- 46 automated tests;
- clean Arch package build validation with `makepkg --cleanbuild --check`;
- protected real-machine audit validation;
- protected guarded/block validation;
- systemd controlled-exit validation;
- AUR identity fail-closed validation;
- a successful guarded-mode real Arch Linux transaction updating 311 packages;
- post-update reboot validation with the new kernel active;
- timer validation with `enabled` / `active` state and the oneshot service
  `inactive` at rest.

## Installation

After downloading the package and checksum file from the GitHub release:

```bash
sha256sum -c SHA256SUMS
sudo pacman -U smart-update-1.1.0-1-x86_64.pkg.tar.zst
```

The administrator configuration under `/etc/smart-update/` is preserved by the
package metadata.
